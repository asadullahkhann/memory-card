# WWE Memory Card Game

A memory game featuring 21 WWE Superstar cards where the goal is to click each card exactly once without selecting the same card twice.

## Features

- 21 WWE Superstar cards
- Random card order after each click
- Scoreboard displaying current score, best score, and wins

## Usage

1. Click a WWE Superstar card.
2. Remember your selections as the cards shuffle after each click.
3. Avoid clicking the same card twice, or the game resets.
4. Click all 21 cards without repeating a selection to win.
